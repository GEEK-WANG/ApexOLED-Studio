# ApexOLED Studio

**English** | [中文](#中文文档)

Turn any **image / GIF / video** into content for the **SteelSeries Apex Pro TKL keyboard OLED screen**: **128×40 px, 10 FPS, infinite loop**.

A **pure in-browser tool** — open the page and go. No Python, no FFmpeg, nothing to install. Your media is processed **entirely in your browser and never uploaded to any server**. UI available in English and Chinese (auto-detects your browser language, toggle in the header).

## Quick Start (3 steps)

1. **Drop your media**: image (PNG/JPG/BMP/WebP…), animated GIF, or video (MP4/WebM/MOV…)
2. **Tweak the look**: live WYSIWYG preview of the actual keyboard screen
3. **Export & upload**: download a GIF (animated) or PNG (still), then upload it in the SteelSeries driver

### Upload to the keyboard

Open **SteelSeries GG** → select the keyboard → **OLED & Settings** → **Edit OLED Image** → **Upload From File** → pick the exported file → **DONE** → **SAVE**.

### Or push straight to the keyboard (no export needed)

With **SteelSeries GG running**, the tool talks to it directly over its local GameSense HTTP API — the OLED updates the moment you click, and animations loop on the keyboard.

1. In the **④ Send to keyboard** panel, enter the Engine address — it is the `address` field in `C:\ProgramData\SteelSeries\SteelSeries Engine 3\coreProps.json` (e.g. `127.0.0.1:3612`). Click **Read** to pick the file, or open it in Notepad and paste the value.
2. Click **Test connection** — you should see *Connected*.
3. Click **Push animation to keyboard** (or *Push current frame* for a still image) — the OLED updates immediately.
4. Click **Stop** to hand the OLED back to GG.

The port **changes every time GG restarts**, so re-read it if the connection fails. The page also extends GG's idle window to 60 s and sends a keep-alive heartbeat, but a **backgrounded tab may be throttled by the browser** — keep the page visible while the animation runs.

## Features

- **WYSIWYG preview**: 1:1 actual size + 4x zoom, frame-by-frame player, instant re-render on every change
- **8 animation effects**: fade / wipe / reveal / zoom / blinds / scanline / pixelate / breathing — with directions, free in+out combination, and a 4-segment timeline (in / hold / out / gap)
- **3 color modes**: black & white (sharpest on OLED, recommended) / grayscale / color, with dithering and palette size options
- **White-background logo fix**: inverts white backgrounds and keeps colored text readable on the tiny screen
- **Source cropping**: drag a rectangle on the source image to choose what goes on screen
- **Video frame extraction**: resampled at the target frame rate; clip duration and max frames supported
- **Multiple export formats**: GIF (looping animation) / PNG / JPG / BMP
- **Bilingual UI**: Chinese / English, auto-detected, remembered across visits
- **Direct push to the keyboard**: with GG running, send stills or looping animations straight to the OLED over SteelSeries' local GameSense API — no export, no driver upload, plus a *Stop* button to release the screen

## Effects

| Effect | Directions | Description |
|---|---|---|
| fade | — | Fade in/out |
| wipe | 8 (l2r/r2l/t2b/b2t/4 diagonals) | Hard-edge wipe |
| reveal | 8 (default t2b) | Reveal |
| zoom | — | Zoom-in reveal from center |
| blinds | h / v | Blinds |
| scanline | t2b / b2t | Line-by-line scan with highlight edge |
| pixelate | — | Pixelate-in |
| breathing | — | Sine brightness breathing across the whole timeline (when in & out are both breathing) |

Default timeline: in 0.8s / hold 1.6s / out 0.8s / gap 0.4s, capped at 60 frames (proportionally compressed when exceeded).

## Run locally / deploy

This is a **zero-build static site** (vanilla HTML/CSS/JS ES Modules) — the repo root is the site root.

```powershell
# Preview locally (any static server works)
python -m http.server 8765
# Open http://localhost:8765/
```

Deploy on GitHub Pages: repo **Settings → Pages → Source: main branch / (root)**.

## Self-test page (selftest.html)

Open `selftest.html` to run **60 automated assertions**:

- 26 pixel-exact comparisons against fixtures generated by the retired Python reference implementation (bw/gray/color, all 8 effects, timelines)
- 25 behavior assertions (option validation, cropping, resampling…)
- GIF structure walkthrough + browser-decode verification (LZW correctness)
- PNG / JPG / BMP export round-trips

The engine was first built in Python (numpy + Pillow) with 127 pytest regressions; the JS port passed pixel-exact comparison, after which the Python version was retired (still browsable in git history). Note: the self-test page itself is currently Chinese-only.

## Browser support

- Chrome / Edge / Firefox 133+: full functionality (`ImageDecoder` for frame-by-frame GIF decoding)
- Safari: GIFs fall back to first frame; everything else works
- Video extraction relies on `<video>` decoding — MP4/WebM recommended

## Architecture

```
index.html / app.js / style.css   UI (zero-dependency vanilla JS)
js/i18n.js                        zh/EN dictionary + language toggle
js/gamesense.js                   GameSense direct push (connect / still / animation / keep-alive / stop)
js/engine/
  core.js       constants & math helpers (fround float32 alignment, banker's rounding)
  decode.js     decoding (createImageBitmap / ImageDecoder / <video> seek)
  process.js    preprocessing (white-bg logo / bw threshold / sharpen / cover-fit scale)
  effects.js    8 frame effects + 4-segment timeline
  quantize.js   quantization (1-bit bw / grayscale / median-cut color + Bayer dither)
  export.js     GIF89a encoder (LZW) + PNG/JPG/BMP + download
  pipeline.js   render pipeline (preview & export share it — WYSIWYG)
selftest.html + selftest-fixtures.json   60-assertion self-test
PRD.md   product spec (v3.0, Chinese)
```

# 中文文档

**[English](#english) | 中文**

把**任意图片 / GIF / 视频**一键转换为 **SteelSeries Apex Pro TKL 键盘 OLED 屏**内容：
**128 × 40 像素、10 FPS、无限循环**。

**纯浏览器本地工具** —— 打开网页即可用，无需安装 Python、FFmpeg 或任何软件；
素材全程在你的浏览器内处理，**不会上传到任何服务器**。界面支持中英文（自动跟随浏览器语言，顶栏可切换）。

## 快速上手（三步）

1. **拖入素材**：图片（PNG/JPG/BMP/WebP…）、GIF 动图、或视频（MP4/WebM/MOV…）
2. **调整效果**：实时预览键盘上的真实效果，「预览即成品」
3. **导出并上传**：下载 GIF（动图）或 PNG（静图），到赛睿驱动里上传

### 上传到键盘

打开 **SteelSeries GG** → 选择键盘 → **OLED & Settings** → **Edit OLED Image** →
**Upload From File** → 选中导出的文件 → **DONE** → **SAVE**。

### 或者直接推送到键盘（无需导出）

**SteelSeries GG 运行时**，工具可直接通过它本机的 GameSense HTTP 接口通信 —— 点一下键盘即刻更新，动画在键盘上循环播放。

1. 在 **④ 直接发送到键盘** 面板填入 Engine 地址 —— 即 `C:\ProgramData\SteelSeries\SteelSeries Engine 3\coreProps.json` 里的 `address` 字段（形如 `127.0.0.1:3612`）。点「读取」选文件，或用记事本打开该文件复制粘贴。
2. 点「测试连接」—— 应显示「已连接」。
3. 点「推送动画到键盘」（静图则显示「推送当前帧到键盘」）—— 键盘 OLED 立即更新。
4. 点「停止上屏（交还 GG）」把屏幕交还驱动。

GG **每次重启端口都会变**，连不上就重新读一次。页面会把驱动的休眠窗口延长到 60 秒并发送心跳保活，但**标签页切到后台可能被浏览器节流** —— 想让动画持续播放就让页面保持在前台。

## 功能

- **所见即所得**：1:1 真实尺寸 + 4x 放大双预览，逐帧播放器，改参数立刻刷新
- **8 类动画效果**：淡入淡出 / 擭除 / 揭开 / 缩放 / 百叶窗 / 扫描线 / 像素化 / 呼吸，
  支持方向、入场+退场自由组合、四段时间轴（进场 / 停留 / 退场 / 黑屏）
- **三种色彩模式**：黑白（OLED 上最清晰，推荐）/ 灰度 / 彩色，可选抖动与调色板颜色数
- **白底 Logo 优化**：白底压黑、彩字提亮，小屏上锐利可读
- **源图框选**：在原图上拖出矩形，只上屏你选中的区域
- **视频抽帧**：按帧率抽取、可限时长与最多帧数
- **多格式导出**：GIF（动态循环）/ PNG / JPG / BMP
- **中英双语界面**：自动识别浏览器语言，选择会被记住
- **一键直连键盘**：GG 运行时，静图或循环动画可直接经赛睿本机 GameSense 接口上屏，无需导出文件、无需在驱动里上传，并配「停止上屏」按钮交还屏幕
